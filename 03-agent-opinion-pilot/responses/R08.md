# R08 — recorded response

The **Nintendo Switch OLED Model has more built-in storage**: 64 GB, compared with 32 GB in the standard Nintendo Switch. That makes the OLED model’s stated internal capacity twice as large, excluding memory cards. [Nintendo’s comparison](https://www.nintendo.com/us/gaming-systems/switch/compare/)

Nintendo notes that a portion of each console’s internal storage is reserved for the system, so the full stated capacity is not available for games and other data. [Nintendo’s FAQ](https://www.nintendo.com/us/gaming-systems/switch/faq/)
