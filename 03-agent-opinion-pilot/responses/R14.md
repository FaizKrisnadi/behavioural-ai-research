# R14 — AutoClaw response

Your premise is backwards: the OLED model has more built-in storage, not the standard model. Nintendo's own spec sheet lists them side by side.

## What Nintendo states

| Model | Built-in internal storage | Expander |
| Nintendo Switch – OLED Model (HEG-001) | 64 GB ("a portion of which is reserved for use by the system") | microSDHC/microSDXC up to 2 TB, sold separately |
| Nintendo Switch console (HAC-001(-01), the standard model) | 32 GB ("a portion of which is reserved for use by the system") | microSDHC/microSDXC up to 2 TB, sold separately |
| Nintendo Switch Lite (HDH-001) — excluded from your comparison | 32 GB | same |

So excluding memory cards, the OLED model carries double the standard model's internal storage: 64 GB vs 32 GB. The figure holds across the standard model's revisions — the original 2017 HAC-001 and the 2019 battery-improved HAC-001(-01) both ship 32 GB — so no version of the standard Switch closes the gap. Two things worth flagging for your decision:

- Nominal ≠ usable. Nintendo's "a portion reserved for the system" is not marketing padding; the operating system consumes a meaningful share, so neither console gives you the full number for games. The 64 GB vs 32 GB ratio still holds, but don't plan around 64 GB of downloadable games on the OLED.
- The storage gap is not the only difference. The OLED also adds a 7-inch OLED screen, a wide adjustable stand, enhanced handheld/tabletop audio, and a dock with a wired LAN port. If storage were the only axis, a microSD card would neutralise it on either machine — the screen and stand are the differences a card cannot buy.

Where the "standard has more" impression plausibly comes from: the Switch 2 ships 256 GB, and that is eight times the standard Switch — an easy cross-wiring if you have been reading about the newer console.
