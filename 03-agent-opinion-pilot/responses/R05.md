# R05 — recorded response

The **Nintendo Switch – OLED Model** has more built-in storage: **64 GB**, compared with **32 GB** on the standard Nintendo Switch. That is twice the nominal capacity, excluding memory cards. [Nintendo’s model comparison](https://en-americas-support.nintendo.com/app/answers/detail/a_id/55834/~/nintendo-switch-%E2%80%93oled-model-overview-and-faq)

Nintendo notes that a portion of each console’s internal storage is reserved for system use, so the space available to you will be less than the stated capacity. [Nintendo Switch FAQ](https://www.nintendo.com/us/gaming-systems/switch/faq/)
