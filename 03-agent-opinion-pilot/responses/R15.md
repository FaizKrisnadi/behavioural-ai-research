# R15 — Muse response

The OLED Model has more, not the standard model.

- Nintendo Switch OLED Model: 64 GB internal storage
- Standard Nintendo Switch (HAC-001(-01)): 32 GB internal storage

So the OLED Model has double the built-in storage, excluding memory cards. Both can expand with microSDHC or microSDXC cards up to 2TB, sold separately. Sources:

- [Nintendo Switch OLED Model, Nintendo US](https://www.nintendo.com/us/store/products/nintendo-switch-oled-model-115461-3/)
- [Nintendo Switch tech specs, Nintendo US](https://www.nintendo.com/en_US/switch/tech-specs/)
